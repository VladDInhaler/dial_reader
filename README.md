# dial reader

reads Input from an old rotary-phone on an arduino sends it away as a string.

It was used as part of a project, where the user could play videos on a screen by dialing numbers on an old rotary phone.


# hardware documentation

The program was used on an Elegoo-Uno (an Arduino-Uno clone) and an old german rotary telephone.

The microcontroller was connected to the telephone with multiple cables etc.

The microcontroller was connected to the telephone plug with jumper cables.

Those where, as far as i remember plugged into the following pins:
- one into the 5V 
- one in Analog in
- one into Analog In or the GND Pin.

The telephone was plugged into a telephone socket and two cables where connected from the socket to the breadboard


The jumper cables used had the colours:
- green (2x) (one probably from bb to telephone socket, the other one from bb to bb)
- black (probably power to the controller)
- white (probably from bb to telephone socket)
- blue (probbaly arduino 
- red (probably to the controller)

Between the telephone and the controller was although a breadboard with a resistance pin.
